MapReduce Data Analysis
This repository contains Python scripts that implement the MapReduce programming model to process and analyze data.

Files in this Repository
wordcount: A Python script designed to count the frequency of words within a dataset.

song_count: A Python script that calculates the total number of times specific songs were played.

songplays: A text document containing the raw dataset used for the song count analysis.

Usage
To run the MapReduce scripts, execute them from your terminal.

Bash
python wordcount
python song_count
(Note: If your scripts require you to pass the dataset as an argument, you can run them like python song_count songplays)
